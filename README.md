## 当前版本功能与使用说明

### 差速混控（Differential Mixing）

本版本已加入双电机差速混控，适用于左右两侧独立驱动的履带车、差速车等。

进入遥控器菜单 **Mixing** 后，可设置：

| 菜单项 | 说明 |
|---|---|
| Mix Mode | Off：关闭；Differential：启用差速混控；Custom：预留模式，当前尚未实现自定义混控 |
| Mix Thr In | 油门输入通道，可选 CH1–CH12 |
| Mix Steer In | 转向输入通道，可选 CH1–CH12 |
| Mix Left Out | 左电机输出通道，可选 CH1–CH12 |
| Mix Right Out | 右电机输出通道，可选 CH1–CH12 |
| Mix Thr Rate | 油门混控比例，0–100% |
| Mix Steer Rate | 转向混控比例，-100% 至 +100%；正负号可改变转向混控方向 |
| Mix Spin | 是否允许左右电机出现相反方向输出，用于原地旋转 |

差速计算关系为：

- 左电机 = 油门 + 转向
- 右电机 = 油门 − 转向

混控结果会限制在 CRSF 通道有效输出范围内。

#### 只用 CH1、CH2 控制两个电机

如果希望只用两个通道操作车辆，推荐将 CH1 作为油门输入、CH2 作为转向输入，并将左右电机输出分别放到 CH1、CH2：

| Mixing 设置 | 选择 |
|---|---|
| Mix Mode | Differential |
| Mix Thr In | CH1 |
| Mix Steer In | CH2 |
| Mix Left Out | CH1 |
| Mix Right Out | CH2 |

这表示 CH1/CH2 的原始输入先参与混控计算，再将计算结果写回 CH1/CH2 作为左右电机输出。无需额外占用 CH3、CH4。用户也可以根据实际摇杆映射和接收机接线选择其他通道组合。

**注意：** 本固件的出厂默认输入仍为油门 CH3、转向 CH4，左右输出为 CH1、CH2；只使用 CH1/CH2 时，需要在 Mixing 菜单中手动更改输入通道。Mix Spin 的代码默认值为 On。初次测试建议架空驱动轮，确认电机方向和转向逻辑后再落地使用；若不需要原地旋转，可将 Mix Spin 设为 Off。油门居中/双向控制还需结合油门通道的 **Center Throt** 设置。

ESP32 C3 Nano TX

ESP32 C3 Nano 尺寸的 ExpressLRS 发射机，最初基于 Simple TX Arduino 发射机项目改造，并增加了一些额外功能。

Simple TX 是由 Kkbin505 开发的一款基于 Arduino 的 ELRS 遥控发射机。他设计了一款软硬件都非常简单易用的 RC 发射机。

我将其重写为运行在 ESP32 C3 模块上，并搭配了一块在速卖通（AliExpress）上只需几美元就能买到的 OLED 屏幕。它的体积足够小巧，甚至比我之前的 TinyTX 项目还要小，而且还内置了 OLED 屏幕！目前我已经实现了从 ELRS 模块读取遥测数据，并完整移植了用于配置 ELRS 和手台的 ELRS Lua 脚本功能。

⚠️ 这是一个活跃维护的仓库！代码和资源仍在持续改进中。
https://youtube.com/shorts/-rPwNI36CTY?feature=share

这款遥控器已经可以正常工作，我对它非常满意。但我确信仍有一些需要修复或改进的地方。现在有了 PCB，组装变得超级简单；3D 打印的外壳也做到了在保证可用性的前提下尽可能小巧。我想研究一下折叠摇杆臂之类的方案以提升握持手感，但机械设计确实有难度。STEP 文件已开源，欢迎有能力的大佬接手优化！

在代码方面，后续主要会聚焦于 Bug 修复，或者如果大家有酷炫的新功能想法（前提是不破坏 UI 的简洁性），也欢迎提出。

核心特性：
真正可放入口袋：不像 Radio Master Pocket 那样带出去还会引人侧目……它是真的能轻松装进口袋。
PS5 霍尔摇杆：即使体积这么小，也不会牺牲磁感应带来的超高精度。
0.42 英寸 OLED 屏幕：显示清晰，UI 简洁易读。
1S 锂电池供电：和你飞 Whoop 穿越机用的是同一种电池。虽未严格测试，但预计使用 1S 300mAh 电池续航可超过 1 小时。
模块化设计：专为使用 100mW 遥测 Nano 接收机作为 TX 模块（RX 改 TX）而设计。同时也支持 ExpressLRS 2.4G 外置 TX 模块，不过那样体积可能比遥控器本身还大。注意：外置模块通常需要独立供电，因为大多数外置模块的工作电压要求在 7V 以上。
最高 500Hz 刷新率：甚至可能支持 FLRC 1000Hz？不过谁会用那么高的频率呢……
4 个模拟通道
3 个 AUX 辅助通道：可通过摇杆按键触发（左摇杆按下切换解锁/Arm，右摇杆按下切换通道 6，长按切换通道 7）。
BLE 蓝牙手柄功能：延迟比直接使用 ELRS 模块自带的 BLE 手柄模式更低。

目前有两种组装方案可选：一种是原始的飞线版（将摇杆导线直接焊接到 ESP32 焊盘上），另一种是 PCB 版（大幅简化了组装流程和时间）。如果你选择飞线版，请注意内部空间非常紧凑，务必确保所有导线长度合适，必要时进行修剪。除非你特别排斥从 PCBWay 或 JLCPCB（嘉立创）打板，否则我强烈建议制作 PCB 版。现在打板真的很方便！

## 🚙 差速混控（双电机车辆）

本版本已加入差速混控，适用于左右两侧分别驱动的双电机车辆，例如履带车或左右独立驱动的车辆。

### 功能说明

在遥控器菜单中进入「混控（Mixing）」：

- **Mix Mode（混控模式）**：Off / Differential / Custom。选择 Differential 启用差速混控；Custom 目前仅为预留选项，尚未实现。
- **Mix Thr In（油门输入）**：选择作为油门来源的 CRSF 通道 CH1–CH12。
- **Mix Steer In（转向输入）**：选择作为转向来源的 CRSF 通道 CH1–CH12。
- **Mix Left Out（左电机输出）**：选择左电机使用的输出通道 CH1–CH12。
- **Mix Right Out（右电机输出）**：选择右电机使用的输出通道 CH1–CH12。左右输出必须选择不同通道。
- **Mix Thr Rate（油门比例）**：0–100%。
- **Mix Steer Rate（转向比例）**：-100% 至 +100%；正负号可用于调整转向混控方向。
- **Mix Spin（原地旋转）**：开启时允许差速计算产生单侧反转；关闭时会限制转向造成的单侧反转。

差速计算采用「左侧 = 油门 + 转向、右侧 = 油门 − 转向」的方式，最终通道值限制在 CRSF 标准范围内。

### 只用 CH1 和 CH2 控制两个电机

如果希望只使用两个通道，可在「混控」菜单中设置：

| 菜单项目 | 设置 |
| --- | --- |
| Mix Thr In（油门输入） | CH1 |
| Mix Steer In（转向输入） | CH2 |
| Mix Left Out（左电机输出） | CH1 |
| Mix Right Out（右电机输出） | CH2 |

这样 CH1 作为油门输入、CH2 作为转向输入，混控结果仍输出到 CH1（左电机）和 CH2（右电机）。程序会先读取输入通道快照，再写入左右输出，因此输入通道与输出通道可以重合；左右输出通道本身不能相同。

注意：CH1、CH2 的实际摇杆来源取决于「Stick Mode（摇杆模式）」及当前通道映射。请先在「Channel Output（通道输出）」页面确认摇杆推动时对应的通道，再进行分配。

### 双向油门与单向油门

- **Center Throt = Yes**：油门以中位为停止点，支持前进和后退，适合支持双向控制的车辆电调。
- **Center Throt = No**：油门以低端为停止点，混控不会主动生成反向油门，适合单向油门用途。

请根据电调的输入方式选择，不要只凭车辆能否倒车来判断；应确认电调是否将通道中位解释为停止、两端解释为正反转。

### 推荐的首次测试步骤

1. 先将车辆架空，确保驱动轮离地；确认电调和机械结构允许安全测试。
2. 先将 Mix Mode 设为 Differential，选择正确的油门、转向和左右输出通道。
3. 将油门/转向比例先设为较低值，确认方向后再逐步提高。
4. 分别测试前进、后退、左转和右转，检查左右电机方向。
5. 只有在电调支持双向控制且确实需要原地旋转时，才开启 Mix Spin。

混控参数保存在 ESP32 的 NVS 设置区，重启后仍会保留。恢复或更换固件时，建议重新检查通道分配及油门居中设置。

- 参数编辑页左上角的短标签（例如 THR、EXPO）保留原始英文显示，避免短标签经过中文字体映射后出现异常字符。
- 恢复菜单浏览页面的方向导航箭头；编辑页面的调节箭头和边框继续保留。
