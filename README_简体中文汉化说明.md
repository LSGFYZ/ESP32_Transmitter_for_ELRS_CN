# ESP32C3-TX 简体中文汉化版（第二版）

## 版本范围

基于原始 `ESP32C3-TX` 工程添加简体中文显示支持。中文映射集中在 `locale_zh_cn.h`，后续修改常见菜单文字时优先改该文件。

## 文件说明

- `locale_zh_cn.h`：英文原文到简体中文的显示映射。左侧英文必须保持与源码或 ELRS 模块返回的文字一致，右侧可按需要修改。
- `oled.cpp`：OLED 的 UTF-8 中文绘制、宽度计算，以及状态/菜单绘制调用。
- `config.cpp`：未将中文写入 NVS 键名；内部参数名仍使用原英文，以免破坏已保存的设置兼容性。
- `libraries/U8g2`：使用项目内置的 `u8g2_font_wqy12_t_gb2312` 中文字体。

## 如何改中文

例如在 `locale_zh_cn.h` 中找到：

```cpp
{"Radio Settings", "遥控器设置"},
```

将右侧文字改为希望显示的中文即可。左侧英文是匹配键，不建议修改。保存后需要重新编译并烧录固件。

如果要翻译新出现的 ELRS 动态菜单项目，可以新增一行 `{ "模块返回的原文", "对应中文" }`。若原文不在映射表里，显示会保留英文，不会篡改 CRSF 数据。

## 字体和资源占用

内置 `u8g2_font_wqy12_t_gb2312` 字体数据表约 202,690 字节（约 198 KiB），会增加固件 Flash 占用；实际链接后的增量要以 Arduino 编译输出为准。中文绘制使用 UTF-8 API，显示字宽按 UTF-8 路径计算。

## 验证状态

本包已进行源码级检查，但当前工作环境未执行 Arduino 实际编译，也未在 ESP32-C3 实机 OLED 上验证。因此请先编译确认 Flash 空间，再检查 72x40 与 128x64 OLED（取决于 `OLED_OPTION_1` 配置）上的中文字形、基线和裁剪。ELRS 模块动态菜单只翻译字典中已收录的文本，未收录的项目会保留英文。
