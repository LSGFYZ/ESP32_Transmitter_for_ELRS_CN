# ESP32C3-TX 简体中文汉化版（第二版）

## 版本范围

基于原始 `ESP32C3-TX` 工程添加简体中文显示支持。中文映射集中在 `locale_zh_cn.h`，后续修改常见菜单文字时优先改该文件。

## 文件说明

- `locale_zh_cn.h`：英文原文到简体中文的显示映射。左侧英文必须保持与源码或 ELRS 模块返回的文字一致，右侧可按需要修改。
- `oled.cpp`：OLED 的 UTF-8 中文绘制、宽度计算，以及状态/菜单绘制调用。
- `config.cpp`：未将中文写入 NVS 键名；内部参数名仍使用原英文，以免破坏已保存的设置兼容性。
- 中文字体：OLED 绘制代码引用 `u8g2_font_wqy12_t_gb2312`；当前 GitHub 仓库未包含独立的 `libraries/U8g2` 子目录，编译前需确认本机安装的 U8g2 库提供该字体。

## 如何改中文

例如在 `locale_zh_cn.h` 中找到：

```cpp
{"Radio Settings", "遥控器设置"},
```

将右侧文字改为希望显示的中文即可。左侧英文是匹配键，不建议修改。保存后需要重新编译并烧录固件。

如果要翻译新出现的 ELRS 动态菜单项目，可以新增一行 `{ "模块返回的原文", "对应中文" }`。若原文不在映射表里，显示会保留英文，不会篡改 CRSF 数据。

## 字体和资源占用

内置 `u8g2_font_wqy12_t_gb2312` 字体数据表约 202,690 字节（约 198 KiB），会增加固件 Flash 占用；实际链接后的增量要以 Arduino 编译输出为准。中文绘制使用 UTF-8 API，显示字宽按 UTF-8 路径计算。

## 当前版本功能补充

### 差速混控

本版本在 `Mixing` 菜单中加入 `Off / Differential / Custom` 三种模式。当前已实现的是 Differential；Custom 仅为预留入口，尚未实现自定义混控。

- 油门输入、转向输入、左电机输出、右电机输出均可分别选择 CH1–CH12。
- 油门比例范围 0–100%；转向比例范围 -100% 至 +100%。
- Mix Spin 用于允许或禁止左右电机反向输出。
- 差速计算：左电机 = 油门 + 转向；右电机 = 油门 − 转向。
- 默认通道分配为油门输入 CH3、转向输入 CH4、左输出 CH1、右输出 CH2。
- 若只用 CH1 和 CH2 控制车辆，可将油门输入设为 CH1、转向输入设为 CH2、左输出设为 CH1、右输出设为 CH2。

## 当前验证状态

差速混控已由项目使用者在实际 ESP32-C3 设备上测试，并反馈运行正常。OLED 编辑页短英文标注保留原样、菜单方向箭头恢复，以及 Channel Output 页面约 30 FPS 刷新已合入主分支。

以上实机反馈不代表所有硬件组合和所有 OLED 尺寸均已覆盖测试。若修改字体、屏幕尺寸或硬件接线，仍需在对应设备上重新编译和验证。

**工程文件说明：** 当前 GitHub 仓库未包含独立的 PlatformIO 工程配置，也未包含 `libraries/U8g2` 子目录或 README 旧网页烧录步骤提到的 `Assets/ESP32C3-TX.bin` 文件。仓库 ZIP 是源码快照，不是可直接网页烧录的二进制固件包。Arduino IDE 编译前需安装 ESP32 开发板和项目依赖，并确认 U8g2 库包含 `u8g2_font_wqy12_t_gb2312` 字体。


## 2026-11-18 功能状态补充

当前 main 分支已包含差速混控和 OLED 显示相关修复：

- 混控菜单支持 CH1–CH12 油门/转向输入及左右电机输出分配。
- 输入与输出通道允许重合，例如油门输入 CH1、转向输入 CH2，同时左电机输出 CH1、右电机输出 CH2。
- 左右输出通道必须不同；Custom 模式目前仅预留，尚未实现。
- 参数编辑页 THR、EXPO 等短标签保留原始英文；菜单方向箭头已恢复。
- Channel Output 页面刷新调度与主页一致，目标约 30 次/秒。
- 差速混控已由项目维护者反馈实机测试正常；本说明不代表所有硬件组合均已测试。

混控使用说明、通道分配示例和安全测试建议请查看主 README 的「差速混控（双电机车辆）」章节。
